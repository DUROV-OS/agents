# Общий контекст компании

Все восемь агентов получают один и тот же пакет `SharedContext`. Специалист не таскает «свою» память мимо остальных.

## Что входит

1. **База знаний** (`vault_backups`) — источник истины. Конституция, журнал решений, профильный раздел `02_Business/`, карточки `03_Clients/`.
2. **CRM** (`amocrm-MCP`) — живые сделки. После чтения факт переносится в базу. CRM слабее позднего `kind: fact`.
3. **Склад / техкарты** (`moysklad-MCP` + Soborbum warehouse) — остатки и BOM. Та же дисциплина: вынуть, проверить, зафиксировать.
4. **Политика** — порог скидки 5%, запрет ворованных данных конкурентов, Human Approval на цену / договор / кадры / банк.

Решение владельца от 2026-09-05: amoCRM и МойСклад — для первичного сбора. Рантайм это уважает: коннектор читает, база хранит, агент цитирует базу в первую очередь.

## Как набирается пакет

Координатор вызывает `ContextStore.gather(text, agents)`.

- Конституция и журнал решений — всегда.
- Профильные `vault_paths` из паспорта разбуженного специалиста.
- CRM-срез — продажнику, маркетологу, финансисту.
- Складской срез — кладовщику, производственнику, финансисту.

Цитата, которой нет в пакете, в ответе специалиста считаться не может. Для разметки это `grounding: contradicted` или `hallucinated`.
