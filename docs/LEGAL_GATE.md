# Юрист как фильтр

Юрист в MVP — не «ещё одно мнение в совете». Это ворота.

```
запрос → legal_gate.scan
         ├─ block            → координатор не будит коммерческих специалистов
         ├─ escalate_human   → можно готовить паспорт, нельзя выпускать действие
         └─ allow            → маршрут + общий контекст + специалисты
                                юрист всё равно вызывается, если категория не none
```

Модель не может ослабить `block`. Если позже появится LLM-юрист, ему разрешено только ужесточить вердикт.

## Пример со звонка

«Возьмём базу клиентов конкурента, которую слил менеджер» → `stolen-competitor-intel` → `block`.

Формулировка человеку: ворованную или слитую информацию конкурентов использовать нельзя. Открытые прайс, сайт, реклама, отзывы — можно, и это уже зона маркетолога после пропуска фильтра.

## Категории

| Категория | Типичный вердикт | Почему |
|---|---|---|
| `competitor_intel_illegal` | block | чужая закрытая база, инсайд, слитый прайс |
| `intellectual_property` | block | чужой чертёж / проект без права |
| `contract` | escalate_human | договор, претензия, подпись |
| `personal_data` | escalate_human | ПДн, паспорт, запись звонка в базу |
| `pricing_authority` | escalate_human | окончательная цена, скидка сверх 5% |
| `owner_promise` | escalate_human | обещание от имени владельца |
| `labor` | escalate_human | найм, увольнение, оклад |
| `safety_code` | escalate_human | несущая, ГОСТ, эвакуация |

Правила лежат в `src/durov_agents/runtime/legal_gate.py`. Новые правила — pull request и gold-пример от `domain_legal` или владельца. ML-инженер не добавляет «можно» без такого примера.
