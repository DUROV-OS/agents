# Восемь агентов MVP

Список зафиксирован. Новых ролей на этой стадии нет (нет HR, нет закупщика, нет «министра стратегии»).

Координатор — лицо для человека. Остальные не разговаривают с рынком мимо него, кроме юридического блока: юрист может остановить выпуск сам.

| id | Кто | Зона | Явно не зона | Вопрос дня |
|---|---|---|---|---|
| `coordinator` | координатор | маршрут, общий контекст, синтез, след | доменные решения | Что сейчас самое важное и кто это закрывает? |
| `sales` | продажник | воронка, следующее действие, черновик КП | окончательная цена, срок без цеха | Какие сделки зависли? |
| `marketer` | маркетолог | контент и факты бренда | чужие закрытые данные, публикация в соцсети | Какой контакт с рынком опирается на факт? |
| `production` | производственник | загрузка, модули, срок цеха | обещание даты клиенту | Что тормозит ближайший дом? |
| `warehouse` | кладовщик | остатки, заявки, приход | оплата поставщику | Чего не хватит ближайшему дому? |
| `finance` | финансист | маржа, порог скидки 5% | банк, инвестиция | Где утекает маржа? |
| `lawyer` | юрист | фильтр риска, паспорт проверки | коммерческая рекомендация | Какое действие нельзя выпускать? |
| `engineer` | инженер | техкарта, СП/ГОСТ, узел | запуск в производство | Какое отклонение от техкарты опасно? |

Паспорта — `src/durov_agents/specs/*.yaml`. Поля совпадают с уставом агента: назначение, зона, запреты, источники, KPI, эскалация.

Это не Марина из Soborbum (`app/ai`) и не совет директоров (`app/board`). Марина — чат сотрудника по разделу системы. Совет — дерево стратегии. Этот репозиторий — операционная команда из восьми ролей с общим контекстом и юридическим фильтром.

Связь с бэкендом по доменам:

- продажник → `/api/clients`, `/api/cycles`
- производственник → `/api/production`
- кладовщик → `/api/warehouse`
- маркетолог → `/api/marketing`
- координатор → `/api/ai` (general), `/api/tasks`
- финансист / юрист / инженер — пока без отдельного раздела API; живут в рантайме и в базе знаний
