## Восемь зон

| Кто | Делает | Не делает |
|---|---|---|
| координатор | маршрут, общий контекст, синтез | цену, срок, договор |
| продажник | воронка, следующее действие, черновик КП | окончательную цену; срок без цеха |
| маркетолог | контент на фактах базы | чужую закрытую базу; публикацию в соцсети |
| производственник | загрузка, модуль, срок цеха | обещание даты клиенту |
| кладовщик | остаток, заявка, приход | оплату поставщику |
| финансист | маржа, порог скидки 5% | банк, инвестицию |
| юрист | вердикт и паспорт проверки | коммерческую идею |
| инженер | техкарта, ГОСТ, узел | запуск в производство |

Запрос идёт так: фильтр юриста → маршрут → общий пакет (база + CRM + склад) → специалисты только своей зоны → выпуск или стоп. Модель не может ослабить `block`.
